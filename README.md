# Fifteen Puzzle

Адаптивна гра "П'ятнашки" (15-puzzle) на чистому JavaScript з лідербордом та плавними анімаціями.

## Посилання

https://mastrophot.github.io/fifteen-puzzle/

## Технології

- Vanilla JavaScript (ES6+)
- CSS3 Glassmorphism + анімації
- Firebase Firestore (лідерборд)
- GitHub Pages (хостинг)

## Локальний запуск

```bash
git clone https://github.com/mastrophot/fifteen-puzzle.git
cd fifteen-puzzle
# Відкрий index.html у браузері
```

## Функціонал

- Класична гра 4x4 з перемішуванням
- Підрахунок ходів і часу
- Тач/клік + клавіатура (стрілки)
- Лідерборд через Firebase (топ-10)
- Конфетті при перемозі
- Збереження прогресу в localStorage
- Адаптивний дизайн
