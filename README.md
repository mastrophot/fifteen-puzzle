# Fifteen Puzzle (П'ятнашки)

Автономна веб-гра «П'ятнашки» (`4x4`) на чистому JavaScript із фізичним FLIP-ковзанням плиток, підтримкою тач-свайпів, синтезом звуку `Web Audio API` та локальною таблицею Топ-10 рекордів.

Живий сайт: https://mastrophot.github.io/fifteen-puzzle/

## Можливості

- **Математично коректний шафл**: алгоритм Фішера–Єйтса з перевіркою парності інверсій та рядка порожньої клітинки (`100%` розв'язні партії).
- **Справжня FLIP-фізика 60/120 FPS**: плавне ковзання як однієї плитки, так і групового зсуву `2–3` плиток у ряду чи колонці за один клік або свайп.
- **Усі способи керування**: клік/тап, свайпи пальцем по плитках або всьому полю (`Pointer Events`), стрілки клавіатури та `WASD`.
- **Чесний таймер**: стартує рівно на першому ході гравця, автоматично ставиться на паузу при згортанні вкладки (`visibilitychange`) і відновлює незавершену партію після перезавантаження сторінки.
- **Звук без зовнішніх MP3**: генерація тонів через `Web Audio API` з автоматичним розблокуванням на iOS/Safari та перемикачем звуку у шапці.
- **Безпека та енергоефективність**: строгий `Content-Security-Policy` (`script-src 'self'`), `0` зовнішніх JS-залежностей, `0%` фонового навантаження на GPU у стані спокою.

## Локальний запуск

```bash
git clone https://github.com/mastrophot/fifteen-puzzle.git
cd fifteen-puzzle
open index.html
```
